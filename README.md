# 坦克大战 Tank Battle

经典 1985 坦克大战（Battle City）复刻版，纯原生 HTML5 Canvas + JavaScript 实现，零依赖、零素材——8-bit 背景音乐与音效全部由 WebAudio 实时合成。

- 在线试玩：<https://godlikecheng.github.io/tank-battle/>
- 技术栈：HTML5 Canvas / WebAudio / 原生 JavaScript，无需构建

## 游戏简介

驾驶坦克保护底部基地（鹰徽），消灭每关全部敌军坦克即可过关。基地被摧毁或生命耗尽则游戏结束。消灭**红色闪烁**的道具携带者会掉落道具。

## 功能特性

- **单人 / 双人合作**：同屏双人，P2 生命独立显示
- **三档难度**：影响敌人速度、子弹速度、开火频率与出生间隔
- **关卡系统**：经典 5 关（致敬 FC 版）+ 30 个精心设计的进阶关卡，共 35 关，通关解锁下一关（进度持久化，可从解锁关卡直接开始）
- **关卡编辑器**：13×13 网格自由绘制，支持试玩、保存与 Base64 分享码导入导出，可勾选「自定义关卡」用于正式闯关
- **6 种道具**：星星、坦克、头盔、炸弹、铁锹、时钟
- **5 种地形 + 基地**：砖墙、钢墙、水面、草丛、冰面（冰面带惯性打滑）
- **4 种敌人**：普通 / 快速 / 强火力 / 装甲，每关 20 辆，配比完全复刻 FC 原版 35 关经典配比表（第 4 / 11 / 18 辆出场为道具携带车）
- **经典规则**：得分达 20000 奖励 1 条生命（1UP）、阵亡后火力重置、2 星双发 / 3 星穿钢
- **关卡结算统计**：各类型击杀数、道具拾取、开炮 / 命中率、本关得分
- **最高分记录**：localStorage 持久化
- **8-bit 背景音乐**：合成旋律，4 档音量；音效含引擎声、暂停音等，可独立开关
- **经典表现**：开场幕布过场（关卡标题）、GAME OVER 逐帧升起动画、得分飘字（含 1UP）、多帧像素爆炸、HUD 剩余敌人图标列
- **丰富配置**：生命数（1-9）、每关敌人数（5-40）、同时在场敌人（2-6 辆）、起始关卡、显示网格
- **细节机制**：出生护盾、子弹互消、敌人简单寻路（偏向基地方向）、转向半格吸附

## 操作方式

| 玩家 | 移动 | 开火 |
|------|------|------|
| P1 | 方向键 | 空格 |
| P2（双人模式） | W / A / S / D | J |
| 通用 | **P** 暂停 / 继续 · **回车** 开始 / 重新开始 / 跳过结算 | — |

## 坦克图鉴

### 玩家坦克

P1 黄色、P2 绿色，生命值为 1，出生自带 3 秒护盾。火力等级通过拾取「星星」升级，跨关卡保留；**阵亡重生后火力重置为 Lv0**：

| 火力等级 | 能力 |
|---------|------|
| Lv0 | 初始状态，单发，开火间隔较长 |
| Lv1 | 开火间隔缩短 |
| Lv2 | 双发（最多 2 发同时在飞） |
| Lv3 | 双发 + 子弹可击穿钢墙 |

### 敌方坦克

| 类型 | 得分 | 速度 | 生命 | 特点 |
|------|------|------|------|------|
| 普通坦克 | 100 | 慢 | 1 | 灰色，中规中矩 |
| 快速坦克 | 200 | 快 | 1 | 蓝色，行动迅速 |
| 强火力坦克 | 300 | 中 | 1 | 橙红色，火力凶猛 |
| 装甲坦克 | 400 | 慢 | 4 | 绿色，需 4 发命中，受击后颜色逐级变深 |

部分敌人随机成为**道具携带者**（红色闪烁），将其消灭即可掉落道具。

## 道具一览

场上同时只存在 1 个道具，出现后约 12 秒自动消失，拾取得 500 分：

| 道具 | 效果 |
|------|------|
| 星星 | 玩家火力等级 +1（上限 Lv3） |
| 坦克 | 生命值 +1 |
| 头盔 | 获得 10 秒护盾 |
| 炸弹 | 立即消灭场上全部敌人 |
| 铁锹 | 基地围墙变为钢墙，持续 15 秒 |
| 时钟 | 冻结全部敌人 8 秒 |

## 地形说明

| 地形 | 特性 |
|------|------|
| 砖墙 | 可被子弹摧毁 |
| 钢墙 | 仅 Lv3 火力可摧毁 |
| 水面 | 阻挡坦克，子弹可飞越 |
| 草丛 | 覆盖在坦克上方，遮挡视线 |
| 冰面 | 可通行；驶上后松开方向键会惯性滑行一小段 |

## 关卡编辑器

点击侧栏「关卡编辑器」打开，复刻 FC 原版 CONSTRUCTION 模式：

- **绘制**：左键绘制 / 右键擦除，按住拖动连刷；基地与双方出生点自动布置（金框 / 红框 / 绿框标记）
- **调色板**：空地、砖墙、钢墙、水面、草丛、冰面 6 种地形
- **试玩**：立即以当前敌人配置开始本关
- **保存**：长期保存后勾选「自定义关卡」，点「开始游戏」即以自定义地图闯关
- **分享码**：导出 Base64 分享码发给朋友，粘贴后点「导入码」即可还原

## 项目结构

```text
tank-battle/
├── index.html        # 页面入口：画布 + 战场情报 HUD + 配置面板 + 关卡编辑器
├── css/style.css     # 样式
└── js/
    ├── constants.js  # 常量、难度参数、道具定义、音乐与音效
    ├── map.js        # 35 个关卡数据、自定义地图加载与随机地图生成
    ├── entities.js   # 坦克 / 子弹工厂、移动与碰撞检测
    ├── game.js       # 游戏流程、敌人 AI、道具系统、冰面打滑、每帧更新
    ├── render.js     # Canvas 渲染（地形 / 坦克 / 子弹 / 幕布 / 特效）
    ├── main.js       # 键盘输入、UI 与配置持久化、主循环
    └── editor.js     # 关卡编辑器（绘制 / 试玩 / 保存 / 分享码）
```
