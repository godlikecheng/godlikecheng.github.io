# 超级马力欧兄弟 Super Mario Bros

经典 1985《超级马力欧兄弟》（Super Mario Bros.）复刻版，纯原生 HTML5 Canvas + JavaScript 实现，零依赖、零素材——程序化像素精灵与 8-bit 背景音乐 / 音效全部由代码合成。

- 在线试玩：<https://godlikecheng.github.io/super-mario-bros/>
- 技术栈：HTML5 Canvas / WebAudio / 原生 JavaScript，无需构建

## 游戏简介

玩家的马力欧穿越蘑菇王国的八个世界，单向前进、顶砖吃道具、踩灭敌人、抵达旗杆过关，最终在 World 8-4 击败库巴、救出公主。坚持与原版一致的规则：触碰敌人或超时损失生命、吃满 100 金币奖励 1 条生命、抵达旗杆时按剩余时间结算加分。

## 功能特性

- **角色状态机**：小马里奥 / 超级 / 火力三种形态，受伤依次降级，小形态伤害即死亡
- **物理手感**：走路与加速跑、跳跃初速与松开按键的短跳截断、惯性起步；水下低重力 + 长按上浮
- **道具系统**：超级蘑菇（变大）、火花（火力形态·可发火球）、无敌星（横冲直撞）、1UP 加命、金币
- **顶砖与砖块**：问号砖顶出金币 / 道具；必出砖（蘑菇 / 火花 / 无敌星 / 1UP）；砖块可被超级形态顶碎；**隐藏砖**（隐形，顶出金币后现身）
- **敌人系统（12 种）**：板栗仔、慢慢龟（绿龟）、硬壳龟（红龟）、刺猬、炮弹刺客、云里花（可抛刺猬）、乌贼、飞鱼、熔岩蹦床、火棒、锤子兄弟、食人花
- **龟壳机制**：可顶出 / 踩踏转龟壳、手持携带、原地跳踢出、踢壳连锁击杀
- **库巴决战**：城堡关岩浆坑桥面 + 铁链装饰，火球 5 发 / 斧头断桥两种击破方式
- **横版关卡**：单向前进、坠坑 / 岩浆即死、按进度生成敌人；关底旗杆过关结算
- **关末演出**：旗杆滑落 → 变向走入城堡 → **时间奖励逐秒滚动结算** → 按末位燃放烟花 → 转场大字卡「WORLD X-X」进入下一关
- **旗杆高度分**：抓杆越高奖励越高；剩余时间每 1 秒 +50，末位 1 / 3 / 6 额外燃放 1 / 2 / 3 发烟花并 +500
- **计分演出**：击杀 / 拾取 / 顶砖实时漂浮数字（+100 / +200 / +400 / 1UP 等）
- **连踩组合**：同一次跳跃连续踩敌逐只递加（第二个 +100、第三个 +200…）
- **奖命机制**：吃满 100 金币 +1 命；累计 20000 分 +1 命
- **地下金币子关**：站在指定管道顶按 ↓ **进入地下金币房**，收集后经出口管道返回主关
- **隐藏跳转（warp）**：部分关的传送点按 ↓ 直达更高世界
- **八世界推进**：世界 1-1 为手工还原的经典开局，其余关由程序生成保证过关链完整
- **开场选关**：开局可直接按 1…8 选择起始世界
- **界面与原版同构**：画面顶部 HUD（MARIO / 分数 / 金币 / WORLD / TIME / 1UP）常驻不滚动
- **主题音乐**：标题 / 陆地 / 地下 / 水下 / 城堡五套 WebAudio 循环，随关卡切换
- **最高分记录**：localStorage 持久化

## 操作方式

| 按键 | 功能 |
|------|------|
| 方向键 ← → / A D | 移动 |
| Z / K | 跳跃（长按跳更高，短按短跳） |
| X / J | 加速跑（跑动后跳得更远、可顶开更高砖）；火力形态下同时发射火球 |
| ↓ / S | 在管道顶按 ↓ 进入地下金币子关；在传送点按 ↓ 跳转世界 |
| 1 … 8 | 开场选关：选择起始世界 |
| P | 暂停 / 继续 |
| 回车 | 开始 / 重新开始 / 继续下一关 |

## 道具与计分

| 道具 / 事件 | 效果 / 得分 |
|------|------|
| 超级蘑菇 | 小形态变大（已变大则 +1000） |
| 火花 | 变为火力形态，可发射火球 |
| 无敌星 | 约 30 秒无敌，触碰敌人直接消灭 |
| 1UP | 剩余生命 +1 |
| 金币 | +200；每满 100 枚奖励 1 条生命 |
| 踩灭板栗仔 / 绿龟 | +100 |
| 踢（静止）龟壳 | +400（连锁击杀敌方再加） |
| 火球击杀敌兵 | +200 |
| 踩踏连击 | 第二次 +100、第三次 +200…（同一次跳跃内） |
| 旗杆高度分 | 抓杆越高递增（100…5000） |
| 过关 | 剩余时间每 1 秒 +50；末位 1 / 3 / 6 额外 +500 并发烟花 |
| 击杀库巴 | +5000 |

## 项目结构

```text
super-mario-bros/
├── index.html        # 页面入口：画布 + 覆盖层 + 信息面板 + 操作说明
├── css/style.css     # 样式（深色面板，与其他游戏一致）
└── js/
    ├── constants.js  # 常量、物理参数、输入、8-bit 音效与五套主题音乐
    ├── map.js        # 瓦片 / 地面数据模型、搭建 API、关卡与地下金币子关构建
    ├── player.js     # 角色形态、走跑跳、瓦片碰撞、顶砖
    ├── entities.js   # 12 种敌人、龟壳、道具实体、火球、火棒、库巴 BOSS
    ├── game.js       # 状态机、世界推进、计分生命时间、时间滚动结算、烟花、地下子关进出、死亡过关
    ├── render.js     # Canvas 像素渲染（瓦片 / 精灵 / 计分 / 转场 / 烟花 / HUD）
    └── main.js       # 键盘输入、开场选关、UI、主循环与启动
```
